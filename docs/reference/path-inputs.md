# 路径输入与选择器盘点

本表记录路径选择器改动的覆盖范围。共用读取入口是核心 `paths.list`，设备接口是声明 `devicePaths` 后的 `litch/paths/list`；只在用户打开或操作选择器时读取目录项，不读取文件内容、不注册模型工具。它不改变文件面板的已知项目根或内容读取规则。

| 场景 | 原有入口 | 本次结果 |
|---|---|---|
| 桌面新建经理工作目录 | 手填，选项目时只读 | 增加共用目录选择器；选择新目录取消项目关联，不修改项目根 |
| 桌面新建项目根目录 | 本机系统对话框、独立远端目录控件 | 统一共用控件，保留手填和候选目录 |
| 桌面编辑项目根目录 | 根目录只读 | 保持只读，不新增修改根目录功能 |
| 桌面普通新建会话 | 项目选择器；无项目用默认目录 | 已有项目选择入口；添加项目使用共用控件，无单独目录文本框 |
| 桌面定时任务的新会话目录 | 项目选择及手填 | 增加共用目录选择器；已有会话目标的目录不编辑 |
| 桌面派出子会话、编辑建议后开始 | 项目选择及手填目录 | 增加共用目录选择器 |
| 设备设置的 CLI 路径 | `path` 类型文本框 | 服务声明 `pathKind=file`，接文件选择器 |
| 工作树存放位置 | `path` 类型文本框 | 服务声明 `pathKind=directory`，接目录选择器 |
| 工作树创建 | 项目、分支及工作树开关 | 没有独立路径文本框，位置由设备设置决定 |
| 设备状态目录 | 运行信息只读显示 | 没有可编辑输入，保持只读 |
| harness 详情的路径设置 | `path` 类型文本框 | 接共用选择器；Claude 的请求头辅助脚本明确为文件 |
| MCP 可执行命令、工作目录 | 文本框 | 分别接文件、目录选择器；命令名仍可手填（如 `npx`） |
| 添加/编辑 SSH 设备的私钥路径 | 本机路径手填 | 接本机系统文件选择器，不连接远端读取私钥 |
| “操作这台电脑”自定义禁止位置 | 客户端本机路径手填 | 提供本机文件、目录选择；不是远端设备路径 |
| 浏览器导入 | 已检测浏览器及资料列表 | 已有来源与资料选择，没有任意文件路径输入 |
| 附件、手机 SSH 私钥导入 | 原有系统/文档选择器 | 保持既有选择器，不将导入改为设备路径选择 |
| 文件查看器的根目录 | 项目/会话根选择 | 不改本轮另一条线负责的 FilesTab、FilesScreen 或根范围逻辑 |
| 手机新建项目根目录 | 手填、独立远端目录控件 | 替换为共用设备路径浏览流程 |
| 手机编辑项目根目录 | 根目录只读 | 保持只读 |
| 手机新建会话 | 项目选择器 | 已有选择；添加项目使用共用控件 |
| 手机定时任务的自定义目录 | 文本提示框 | 保留手填，增加设备目录选择按钮 |
| 手机建议任务/子会话目录 | 手填 | 增加设备目录选择按钮 |
| 手机设备 CLI/工作树路径设置 | 文本框 | 接对应文件/目录选择器 |
| 手机 harness 路径设置 | 文本框 | 接共用设备路径选择器 |
| 手机创建经理、MCP 修改 | 未开放创建经理；MCP 只读 | 没有可接的输入框，不新增这些功能 |

`pathKind` 是服务声明，客户端不按设置键名猜测文件或目录；未声明的路径字段提供两个选择按钮。手机始终浏览连接设备，桌面本机优先系统对话框，远程使用应用内浏览器。

路径浏览保留符号链接类型与目标类型；文件的可执行标记由目标设备元数据决定（POSIX 使用服务进程用户的 X_OK，Windows 使用 PATHEXT），不试运行文件。每次最多返回 2000 项；超出时明确提示仍可直接填写完整路径。

旧设备没有 `devicePaths` 能力时不发送未知请求，选择器说明手填或升级；即使服务宣告能力却回方法不存在，也给相同提示。已有 `files.list` 的已知根检查与文件内容权限不变。

## 局部验收入口

- `packages/device/test/path-picker.test.mts`：真实临时目录、执行权限、正常与失效链接、声明门控、目录错误、返回值不含文件内容。
- `packages/core/test/path-picker.test.mts`：用户命令到设备接口、目录/文件过滤、目标 home、旧设备拒绝发送、方法不存在提示。
- `apps/desktop/src/probe-manager.mts`：经理里的远程选择器、逐层进入、手动跳转、取消与确认、外层表单不误提交、布局顺序。
- `apps/desktop/src/probe-organize-mock.mts`：本机系统目录选择（夹具代答）回填项目根。
- 可选隐藏截图：`LITCH_FIXTURE_PATH_PICKER_SHOT=/tmp/path-picker.png node apps/desktop/scripts/smoke.mjs --manager`，先构建 UI 与桌面。
